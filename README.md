# Switching-Lab

Webové virtuální prostředí na switching a routing ve stylu Cisco labů. Vybereš si téma a obtížnost a dostaneš náhodnou úlohu.

## 🧪 Labs
Procvičování switchingu a routingu: **21 úloh** ve **4 obtížnostech**.

## 🔌 Topology
Nauč se sestavit síť a správně zvolit kabeláž mezi prvky.
- **Prvky:** router, switch, multilayer switch, DHCP server, PC
- **Kabely:** straight-through, crossover
