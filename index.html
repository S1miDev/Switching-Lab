      CCNA command reference

      Each topic covered by the labs, grouped by CCNA area.

      Core12 topics
      IPv4 addressing
      Dotted-decimal addresses paired with a mask to split network and host bits.
      Subnetting
      Borrow host bits to create smaller networks, then count blocks and hosts.
      Variable Length Subnet Masking (VLSM)
      Size each subnet to its host need instead of using one fixed mask.
      Static routing
      Manually defined routes to remote networks that stay fixed until someone changes them.
      Default routes
      The gateway of last resort, used when no more specific route matches.
      OSPFv2 (IPv4)
      Link-state routing for IPv4 that builds a topology map and runs SPF.
      VLANs
      Split one switch into separate broadcast domains.
      Access ports
      A switch port carrying one VLAN for an end device.
      Trunking (802.1Q)
      A link carrying several tagged VLANs, with one untagged native VLAN.
      Inter-VLAN routing
      Route between VLANs with a router-on-a-stick or an SVI.
      Spanning Tree (STP)
      Blocks redundant Layer 2 links to prevent loops.
      EtherChannel
      Bundles links into one logical link for bandwidth and redundancy.
      IP & routing3 topics
      OSPFv3
      OSPF for IPv6, run per link and identified by a router ID.
      IPv6 addressing
      128-bit addresses with unicast, multicast, and anycast types.
      IPv6 routing
      Static routes, RIPng, OSPFv3, and EIGRP for IPv6.
      Switching3 topics
      Advanced STP
      Rapid PVST+ and guard features for faster convergence and stability.
      Advanced EtherChannel
      Load balancing, Layer 3 bundles, and consistency checks.
      CDP and LLDP
      Discover directly connected neighbours using Cisco and open-standard protocols.
      Services5 topics
      DHCP
      Automatic IPv4 address assignment using the DORA exchange.
      DHCP relay
      Forward DHCP broadcasts across subnets with ip helper-address.
      NAT
      Translate private addresses to public ones: static, dynamic, or PAT.
      NTP, syslog, DNS
      Clock synchronisation, central logging, and name resolution.
      QoS
      Classify, mark, and prioritise traffic during congestion.
      Security6 topics
      Standard and extended ACLs
      Filter IPv4 traffic top-down, with an implicit deny at the end.
      IPv6 ACLs
      Always named, with implicit permits for neighbour discovery.
      Port security
      Limit which MAC addresses an access port will accept.
      Device hardening
      Secure local and remote access, and use SSH instead of Telnet.
      DHCP snooping
      Filter DHCP messages and build a binding table.
      Dynamic ARP inspection
      Check ARP packets against the snooping binding table.
      Wireless2 topics
      WLAN fundamentals
      RF basics, access point modes, and controller-based deployment with CAPWAP.
      WLAN security
      Open, WPA, and 802.1X authentication options on a WLC.
      Management2 topics
      Device management
      Time sync, logging, monitoring, and secure file transfer.
      Network automation
      Moving from device-by-device CLI work to APIs and configuration tools.
      Troubleshooting1 topic
      Structured troubleshooting
      Work up through the OSI layers to isolate faults instead of guessing.
